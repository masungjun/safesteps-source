# SafeSteps

등하굣길 위험 요소를 지도에 기록하고, 민원 문안으로 정리해 직접 신고하도록 돕는 도구입니다. Vite + React 19 + TypeScript + Leaflet.

## 실행

```bash
pnpm install
pnpm dev --port 5184
pnpm build
```

## 주요 흐름

1. 위험 제보하기 → 지도를 눌러 핀을 놓고(끌어서 이동 가능) 내용과 사진을 입력합니다.
2. 제보 상세에서 민원 문안을 복사해 안전신문고에 직접 신고합니다.
3. 진행 상태를 접수 전 → 신고함 → 처리 완료로 바꾸면 변경 이력이 남습니다.

## 데이터 저장

서버 없이 `localStorage`에만 저장합니다. 사진은 긴 변 1024px JPEG로 줄여 저장합니다.

- `safe-map-reports`: 제보(사진, 상태 이력 포함). 이전 상태 "확인 중"은 "접수 전"으로 옮겨집니다.
- `safe-map-liked`: 이 기기에서 공감한 제보
- `safesteps-lang`: 언어

CSV, GeoJSON, JSON으로 내보낼 수 있고, JSON과 GeoJSON을 가져올 수 있습니다. 같은 제보(id 또는 제목과 좌표 일치)는 건너뜁니다.

## 한계

- 제보는 이 기기에만 있어 다른 사람과 자동으로 공유되지 않습니다. 파일로만 옮길 수 있습니다.
- 앱이 기관에 자동 접수하지 않습니다. 신고는 사용자가 직접 합니다.
- 기본 제보 4건은 예시이며 활동소식의 수치에서 제외합니다.
- 지도 타일은 OpenStreetMap을 사용하므로 인터넷 연결이 필요합니다.
